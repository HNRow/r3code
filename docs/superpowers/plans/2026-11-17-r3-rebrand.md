# R3 Rebrand Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把 R3 Code 的用户可见品牌展示统一改为 R3 Code，并把 SVG 字形从 “T3” 改为 “R3”。

**Architecture:** 采用混合式方案：脚本批量替换用户可见文本，手动替换统一的 SVG path，再用现有脚本重新生成各平台图标。代码标识符、包名、bundle ID、URL scheme、环境变量、本地存储键保持不变。

**Tech Stack:** TypeScript/React/React Native/Electron、SVG、Node.js 脚本、Vite+ (`vp`)。

## Global Constraints

- 只改用户可见品牌展示，不改 `@t3tools/*`、`T3CODE_*`、`t3code://`、`com.t3tools.t3code`、本地存储键、内部模块名。
- 所有 wordmark 使用同一段 path，统一替换为新的 R3 path。
- 文本替换只改值，不改 i18n key 和插值结构。
- 原生图标通过现有脚本重新生成，不手动编辑 PNG。
- 除非用户明确要求，否则不执行 `git commit`。

- [ ] **Step 1: 创建批量替换脚本**

```js
// scripts/rebrand-r3-text.mjs
import { readdirSync, readFileSync, statSync, writeFileSync } from "node:fs";
import { join } from "node:path";

const ROOTS = ["apps", "docs", "scripts", "packages", "assets"];
const EXTENSIONS = new Set([
  ".ts",
  ".tsx",
  ".js",
  ".jsx",
  ".mjs",
  ".cjs",
  ".json",
  ".md",
  ".astro",
  ".xml",
  ".nsh",
  ".svg",
  ".html",
  ".txt",
  ".yml",
  ".yaml",
  ".toml",
  ".webmanifest",
]);
const EXCLUDE_DIRS = new Set([
  "node_modules",
  ".git",
  ".repos",
  "dist",
  "build",
  ".next",
  "coverage",
  ".turbo",
  ".vite-plus",
  ".expo",
  ".simulator",
]);

function walk(dir) {
  for (const entry of readdirSync(dir)) {
    if (EXCLUDE_DIRS.has(entry)) continue;
    const path = join(dir, entry);
    const stat = statSync(path);
    if (stat.isDirectory()) {
      walk(path);
      continue;
    }
    const ext = entry.includes(".") ? `.${entry.split(".").pop()}` : "";
    if (!EXTENSIONS.has(ext)) continue;
    const original = readFileSync(path, "utf8");
    const updated = original
      .replaceAll("R3 Code", "R3 Code")
      .replaceAll("T3 Connect", "R3 Connect");
    if (updated !== original) {
      writeFileSync(path, updated);
      console.log(`updated ${path}`);
    }
  }
}

for (const root of ROOTS) walk(root);
```
